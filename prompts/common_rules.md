# Common Power BI Build Rules

1. Plan before implementation.
2. Never modify files outside the current stage.
3. Never invent requirements.
4. Use Power BI skills whenever applicable.
5. Validate after implementation.
6. Correct failures before proceeding.
7. Never silently bypass validation.
8. Preserve user-created slicers unless explicitly instructed.
9. Use the approved theme.
10. Use medium visual density.
11. Use consistent navigation.
12. Prefer minimal changes.
13. Stop for HITL when business judgment is required.
14. Do not proceed from a failed stage.
15. Final delivery requires both static and Power BI Desktop QA.
